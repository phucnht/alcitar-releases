# AlciTar releases

macOS downloads for AlciTar, a free, offline guitar practice player for your own Guitar Pro files. Download it from the site at https://phucnht.github.io/alcitar-releases/ or from the [Releases](https://github.com/phucnht/alcitar-releases/releases) page. The source code is private; this repository holds only the site and the built `.dmg` files.
